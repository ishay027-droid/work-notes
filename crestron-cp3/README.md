# Crestron CP3 AV Control Starter

Starter architecture for a Crestron CP3 controlling a Sony projector and Symetrix audio DSP.

## Current scope
- System ON / OFF
- Sony projector power and input placeholders
- Symetrix volume and mute placeholders
- Source selection
- Room shutdown sequence

## Important
This is a hardware-independent starter. Exact RS-232/IP commands must be filled in after the Sony projector and Symetrix model numbers are known.

Recommended implementation: SIMPL# Pro / C# with SIMPL Windows integration.
